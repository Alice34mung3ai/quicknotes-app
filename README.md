# Quick Notes

Quick Notes is a simple web application for creating, organizing, searching, and deleting notes.

## Features

* Add notes with a category.
* Display the note text, category, and creation date and time.
* Validate empty notes and notes longer than 200 characters.
* Delete individual notes.
* Display the current number of notes.
* Save notes using browser localStorage.
* Search notes as you type.
* Search is not case-sensitive.

## Technologies Used

* HTML
* CSS
* JavaScript
* Browser localStorage

## How to Use

1. Open the application in a web browser.
2. Enter a note in the Note field.
3. Select a category.
4. Click **Add Note**.
5. Use the search field to find notes.
6. Click **Delete** to remove a note.

Notes are saved in the browser's localStorage, so they remain available after refreshing the page.

## Project Files

* `index.html` — page structure and content.
* `style.css` — layout and visual styling.
* `script.js` — note creation, validation, deletion, counting, persistence, and search.
* `README.md` — project documentation.
